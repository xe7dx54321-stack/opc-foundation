Document Extraction Foundation

Universal Public Document Extraction Infrastructure

Overview

The Document Extraction Foundation provides a universal public document extraction infrastructure for various document types.

Key Features

  • Local PDF text extraction
  • HTML content extraction
  • Plain text processing
  • Markdown parsing
  • Document hash computation
  • Quality assessment

Supported Document Types

Type Extension Description
PDF .pdf Portable Document Format
HTML .html, .htm HyperText Markup Language
Text .txt Plain text files
Markdown .md, .markdown Markdown documents

Architecture

The architecture consists of:

  1. DocumentArchiver - Main orchestrator
  2. Extractors - Format-specific extractors
    • PDFExtractor
    • HTMLExtractor
    • TextExtractor
    • MarkdownExtractor
  3. Storage - JSONL-based storage
  4. Health - Source health monitoring

Disclaimer

This module provides infrastructure only.

Business logic remains with the consuming system.
